# 无忧计划

- 脚本：`无忧计划.py`
- 来源：`https://github.com/525815266/YYB-Go-Enhanced`，原文件 `scripts/无忧计划.py`
- 文件最后提交：2026-09-28，提交 `ad3e18d199620031edd06c6bb5cc252615cd0934`
- 语言：Python
- 定时：脚本头未注明，建议每天跑一次，时间自定
- 环境变量：`WY_ACCOUNT`，格式 `账号#密码#device_id#备注`，多账号换行分隔；可选 `PROXY_API`、`PROXY_TYPE`、`WY_USER_AGENT`；通知可选 `PUSHPLUS_TOKEN`（脚本内默认值为空，自己填环境变量才推送）
- 配置方法：先在无忧计划 App 注册好账号，账号密码独立版，不依赖 YYB 微信账号。不要把账号密码写进仓库，只填青龙环境变量。
- 青龙任务命令：`task wuyou/无忧计划.py`
- 通知：跑完（成功和失败都发）会发青龙通知，标题格式为“无忧计划：X成功/Y失败”，正文为执行汇总（成功几/总计几、每账号登录/签到/任务/广告/金币结果、失败原因首行）+ 日志尾部最多 30 行，总长截到约 1800 字符（企业微信应用消息有长度限制，完整日志见青龙运行日志）。原 PushPlus 推送不变。
- 通知通道：优先调青龙面板本地接口 PUT /open/system/notify（带系统 token），走面板“系统设置/通知设置”里配好的渠道（如企业微信）。以前只调 notify.py / sendNotify.js 时收不到，是因为它们只读 QYWX_AM 等环境变量，读不到面板数据库里的配置；`ql notify` 这个子命令在青龙 2.24.0 上不存在。面板接口失败时会在日志里写明原因，再试 notify.py / sendNotify.js（仅环境变量渠道有效）。
